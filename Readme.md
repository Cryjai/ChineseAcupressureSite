## 📖 About

A web-based reference tool for Traditional Chinese Medicine (TCM) acupressure points (穴位). Users can explore acupoints by body region, view detailed descriptions, and learn about their therapeutic uses — all in Chinese.

Built as a static site with zero dependencies, pure HTML/CSS/JavaScript only.

---

## ✨ Features

- 🗺️ **Interactive body map** — click regions to explore related acupoints
- 📍 **Detailed point info** — location, function, and usage for each 穴位
- 🔍 **Search & filter** — quickly find the point you need
- 📱 **Responsive design** — works on mobile and desktop
- 🇨🇳 **Full Chinese language interface**

cd ChineseAcupressureSite
open index.html
